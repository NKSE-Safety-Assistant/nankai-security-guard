# 消防活动三块立屏内容方案

> 当前为内容初稿。收到保卫处老师给出的立屏尺寸后，再按实际宽高比完成印刷版排版。

## 立屏一：项目与思政育人

### 主标题

南开校园安全卫士

### 副标题

科技赋能安全教育，让责任意识转化为应急行动

### 核心文案

项目依托思政实验室建设，面向全校师生，将价值引领、安全责任与真实校园情景相结合。通过智能问答、情景演练和实践反馈，引导师生从“知道安全”走向“会判断、会行动、敢担当”。

### 展示要点

- 思政育人：把守护他人、服务集体融入安全教育
- 情景育人：以校园真实案例训练判断与协作能力
- 实践育人：形成学习、演练、上报、复盘的完整闭环

## 立屏二：四项核心能力

### 主标题

会问 · 会学 · 会报 · 会管

### 四项能力

1. **会问**：飞书智能体提供校园安全咨询与应急处置指引。
2. **会学**：消防知识任务支持即时判分、答案解释和学习记录。
3. **会报**：一键求助与隐患上报帮助师生准确说明地点、风险和人员情况。
4. **会管**：管理后台支持任务发布、题库维护、学习统计和内容审核。

### 现场提示

触摸 78 寸展示屏，亲自完成一次消防安全判断。

## 立屏三：消防专题体验

### 主标题

把安全避险能力练成第一反应

### 体验内容

- 三角色情景演练：体验者、帮助者、观察者
- 四步判断：识别风险、及时处置、有效上报、复盘提醒
- 典型场景：宿舍用电、实验室电器起火、疏散通道堵塞
- 智能问答：浓烟逃生、灭火器使用、初起火灾处置

### 行动口号

人人讲安全，个个会应急；守护自己，也守护身边的人。
