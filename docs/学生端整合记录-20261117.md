# 学生端前端整合记录

## 来源与范围

合入“南开安全卫士-学生端前端修改包-20261117-150254.zip”中的 app.js、knowledge.html、preview-unify.css 与 assets/scenario-covers 下的十张 PNG 封面。开发同学提供的原始说明另存为本目录下的《学生端前端修改说明-开发同学原稿-20261117.md》。

本次采用提供文件与当前文件逐项比较的方式合入，保留同学设计的首页、日常学习分级入口、聊天气泡、连续聊天记录、脑中想法和结局复盘界面。未覆盖管理员、编辑员、审核员页面及共享后台资源，也未调整服务端、数据库结构、登录权限或题库规则。

## 数据核对

包内 safety-case-db.json 与当前库均为 24 条案例，案例 ID 一致，未增加或删除案例；核心情景内容一致。差异涉及更新日期、一个来源日期以及采集运行记录。新版独立封面通过前端案例 ID 映射绑定，不依赖替换数据库。因此保留本地案例库及采集记录，未用包内旧快照覆盖，也未导入或重置 MySQL。现有 315 道题、50 道消防题、展示用 10 个情景及学习任务继续沿用。

## 整合时修复

### 动态案例封面补齐

后续补充：已为修改包内缺图的“大型活动消防”新增 campus-fire-awareness-event.png，作为情景示意插图，非真实活动照片。新增“消防安全::大型活动消防”映射，场景卡片、角色选择、剧情插图与结局复盘共用该封面。当前资源为原包十张加新增一张，共十一张。浏览器已确认第四个情景显示消防器材讲解插图，相关封面检查通过；下文“仍使用通用展示”是补图前的排查结论，已由本次修复取代。

再次核对压缩包内十张封面与项目文件，SHA256 全部一致，图片没有漏拷贝。此前前端仅按十个固定案例 ID 匹配封面；MySQL 中动态采集的“关于钓鱼邮件防范的紧急通知”使用生成 ID，因此没有命中。现保留固定 ID 映射，并增加安全类型与具体情景的组合匹配，避免仅按大类套用无关图片。浏览器已确认第七个动态钓鱼案例使用 phishing-login.png。测试覆盖固定 ID、生成 ID 和无对应素材的情景。新增“大型活动消防”案例在修改包内没有专用图片，仍使用原有通用展示；本次未替换其素材，也未改动数据库内容或案例排序。

- 新版学习区新增了 hidden 状态，但任务开始仅切换 active 样式，会导致任务题目仍被隐藏。现统一同步 active 与 hidden，任务和日常答题均可显示。
- 移除“返回任务列表”的重复监听，恢复返回后重新读取任务与完成情况的流程。
- 学生端样式及脚本缓存版本更新为 20261117-integrated。

## 查看方式

### 学生与工作人员入口分离

学生页顶部已移除“学生学习 / 切换角色”，只保留平台标识。工作人员从页脚的“工作人员入口”进入 admin-login.html，也可收藏该独立地址；该页只提供管理员、编辑员、审核员三种身份登录。学生学习平台仅以普通返回链接出现在后台登录页底部，不再作为工作人员登录身份。角色选择仍调用原有登录与权限校验，并不会授予账号额外权限。

本地服务运行时打开 http://localhost:8021/knowledge.html 。已有页面若未更新，按 Ctrl+F5 强制刷新。当前仅整合本地项目，尚未推送或发布至线上。
