# 南开安全卫士学生端前端修改说明

## 一、修改范围

本次修改仅针对“南开安全卫士”学生端知识学习页面，主要优化学习入口、三角色情景、聊天记录、脑中想法和结局复盘的界面与使用流程。

未修改管理员端、编辑员端、审核员端、服务端接口、数据库程序、身份认证和学习记录提交规则。

## 二、学习页面结构调整

### 1. 学习首页

- 首页只保留“学习任务”和“日常学习”两个主要入口，不再直接展开下级内容。
- 学习任务进入后才显示老师布置的任务、截止时间和完成情况。
- 学习任务与日常学习页面均提供返回学习首页的入口。

### 2. 日常学习

- 日常学习页面只展示“安全答题”和“三角色模式”两个入口。
- 进入任一模式后隐藏上方两个入口，避免重复占用空间。
- 模式内部的返回按钮统一为“返回日常学习”。
- 统一“三角色模式”和“三角色情景”等相关页面名称。

## 三、安全答题界面

- 保留原有题目、选项、计分、反馈和下一题逻辑。
- 优化题目区域、选项卡片、进度信息和反馈信息的视觉层级。
- 未修改题库规则和答题判断逻辑。

## 四、三角色情景界面

### 1. 场景选择

- 为十个校园安全情景配置了与内容相符的独立封面。
- 封面覆盖宿舍用电、实验室插座冒烟、疏散通道堵塞、食堂油锅起火、电动车电池冒烟、刷单返利诈骗、违规充电、夜间尾随、化学废液混合和钓鱼登录等场景。
- 优化场景卡片、场景切换和角色选择区域。

### 2. 进入情景后

- 隐藏场景介绍区及案例来源等重复内容。
- 页面只保留当前剧情、聊天记录、脑中想法和“返回场景选择”。
- 调整电脑端内容区域高度与滚动方式，避免聊天内容被遮挡。

## 五、聊天记录优化

- 将自己、其他角色和系统提示设计为不同的消息样式。
- 自己的消息靠右，其他角色消息靠左，系统提示居中。
- 优化头像、气泡方向、颜色、圆角、间距和文字可读性。
- 选择“脑中想法”后，选择内容会作为自己的消息追加到聊天记录。
- 后续消息继续追加，之前的对话记录会保留。
- 增加重复消息判断，避免同一选择结果重复出现。

## 六、“脑中想法”区域

- 将脑中想法设计为独立选择面板，与聊天记录明确区分。
- 选项增加序号、边框和方向提示。
- 移除阴影动画、复杂位移动画等可能造成卡顿的效果。
- 保留原有“点击选项后直接推进剧情”的逻辑。

## 七、结局复盘界面

- 所有结局统一采用“结局说明 + 当前情景插图 + 学习要点”的结构。
- 结局插图自动使用当前情景对应封面，不会共用同一张图片。
- 安全、警示和风险结局使用不同状态颜色与图标。
- 学习要点采用两列卡片布局，奇数项的最后一项自动铺满。
- 放大学习要点正文与序号，提高可读性和整体协调性。
- 未增加顶部面包屑，也未增加底部返回和重新体验按钮。
- 继续使用页面原有的“返回场景选择”入口。

## 八、响应式与性能调整

- 保留电脑端主体排版，并为窄屏和手机端提供单列布局。
- 手机端聊天气泡、脑中想法和结局学习要点会自动调整宽度、字号与间距。
- 减少大面积动态阴影、模糊和复杂动画，降低滚动与交互时的重绘压力。
- 更新 CSS 和 JavaScript 版本参数，避免浏览器读取旧缓存。

## 九、涉及文件

| 文件 | 主要作用 |
| --- | --- |
| `knowledge.html` | 学生端学习入口、情景及结局页面结构 |
| `app.js` | 页面切换、聊天记录保留、消息去重和结局插图绑定 |
| `preview-unify.css` | 学生端整体视觉、聊天气泡、脑中想法及结局复盘样式 |
| `data/safety-case-db.json` | 当前校园安全情景数据调整 |
| `assets/scenario-covers/` | 十张不同情景的封面图片 |

## 十、未改动内容

- 未改变安全答题的计分和判题规则。
- 未改变三角色剧情分支、结局判定和学习完成记录逻辑。
- 未修改管理员端、编辑员端和审核员端页面。
- 未修改服务端接口、MySQL 结构、飞书登录和权限控制。
